## 2. Temuan

### F-01 — `pointercancel` meng-commit gambar yang belum selesai (MEDIUM) — DIPERBAIKI
- **Reproduksi:** tool Rectangle → pointerdown + drag → dispatch `pointercancel` → pointerup.
- **Expected:** gesture yang dibatalkan sistem tidak menghasilkan shape (seperti menekan Escape).
- **Actual (sebelum fix):** shape setengah jadi ter-commit dan ikut terseleksi (`1 shape 1 selected`).
- **Bukti:** E2E `pointercancel discards an in-progress create` gagal pre-fix; statusbar menunjukkan `1 shape 1 selected`.
- **Penyebab:** `pointercancel` di-route ke handler `onPointerUp` yang meng-commit semua mode drag.
- **Perbaikan:** handler khusus `onPointerCancel` — lepas pointer capture, buang transient state, tanpa commit, seleksi tidak diubah (`src/interaction/controller.ts`).

### F-02 — Pointer kedua saat drag membajak interaksi (MEDIUM) — DIPERBAIKI
- **Reproduksi:** drag shape dengan pointer 1 → pointerdown kedua (pointerId berbeda) di area kosong → lanjutkan drag pointer 1 → pointerup.
- **Expected:** pointer kedua diabaikan; drag pertama selesai normal.
- **Actual (sebelum fix):** mode drag tertimpa jadi `marquee`, pointerup pointer 1 diabaikan → shape tidak pindah, seleksi ter-clear (`0 selected`), sisa ghost preview di kanvas, mode terkunci sampai interaksi berikutnya.
- **Bukti:** E2E `a second pointer during an active drag is ignored` gagal pre-fix (`1 selected` tidak ditemukan).
- **Penyebab:** `onPointerDown` tidak memeriksa apakah drag sedang berjalan; pointer baru menimpa `this.mode`.
- **Perbaikan:** abaikan pointerdown dengan pointerId berbeda saat drag aktif (`src/interaction/controller.ts`). Relevan untuk sentuhan multi-jari / telapak tangan di tablet & HP.

### F-03 — Fitur ekspor/impor JSON tidak ada (INFO, bukan bug)
- Permintaan audit mencakup "round-trip ekspor/impor JSON", tetapi tidak ada UI maupun fungsi ekspor/impor JSON di kode (`grep` tidak menemukan; satu-satunya serialisasi adalah IndexedDB internal). Tidak ada yang bisa diuji; **bukan bug**. Validasi dokumen (`isValidDocument`) sudah ada dan teruji via E2E (data korup diabaikan saat load).

### Observasi code review — belum terbukti via E2E (LOW, tidak diperbaiki)
- Jika pengguna menggambar dalam milidetik pertama saat dokumen IndexedDB masih loading, `loadDocument()` yang terlambat resolve dapat menimpa gambar tersebut dengan dokumen tersimpan. Jendela race sangat kecil dan tidak berhasil direproduksi deterministik di E2E, sehingga sesuai aturan audit ("perbaiki hanya bug yang terbukti") tidak diubah.

## 3. Perbaikan yang dilakukan

Hanya dua perbaikan di atas, keduanya kecil dan terarah di `src/interaction/controller.ts`:
1. Handler `onPointerCancel` terpisah (tidak lagi memakai `onPointerUp`).
2. Guard pointerId di `onPointerDown`.

Tidak ada refactor besar; tidak ada backend, autentikasi, AI, atau kolaborasi yang ditambahkan.
